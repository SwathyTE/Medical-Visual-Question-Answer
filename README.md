# 🩺 Medical Visual Question Answering using MedGemma

A Medical Visual Question Answering (Med-VQA) system that combines medical image understanding and natural language processing to answer questions related to medical images.
The project explores the use of Google's MedGemma multimodal model for understanding medical images and generating relevant textual answers to clinical questions.
Overview:
Medical Visual Question Answering (Med-VQA) is a multimodal AI task where a model receives:
1. A medical image
2. A natural-language question about the image
and generates an appropriate answer.

The main objectives of this project are:

- Build a Medical Visual Question Answering pipeline.
- Prepare and structure medical image-question-answer data.
- Fine-tune a multimodal medical language model.
- Generate answers for questions related to medical images.
- Evaluate model predictions against expected answers.
- Validate the model's performance on unseen examples.
- Explore the application of multimodal AI in medical image understanding.
